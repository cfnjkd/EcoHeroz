EcoHeroz 🌍 | AI Object Detection for Recycling
AI object detection tool for recycling education. Developed with Roboflow and trained on 2,000+ images for FreshHacks 2024.


Devpost Submission: [https://devpost.com/software/ecoheroz]

EcoHeroz is an AI-powered educational tool designed to help the youth identify recyclable materials using real-time object detection. By leveraging computer vision and a dataset of 2,000+ images, the project aims to gamify environmental sustainability and reduce global waste.
